Reverse Nodes in k-Group

LeetCode 25 — Reverse every k nodes in a linked list

Linked List Recursion

Problem Overview

Reverse the nodes of a linked list k at a time. If the last group has fewer than k nodes, leave them as-is.

Input: head = [1,2,3,4,5], k = 2 Output: [2,1,4,3,5]

Approach 1: Recursive

Intuition: Reverse first k nodes, then recursively reverse the rest.

Time: O(n) Space: O(n/k)
Recursive pattern
Reverse first k nodes
Connect to recursive call on remaining
Base case: fewer than k nodes, return as-is

Elegant but uses O(n/k) recursion stack space.

Approach 2: Iterative (Implemented)

Intuition: Count nodes, reverse each group of k iteratively.

Time: O(n) Space: O(1)

Result
  1. Count total nodes in the list
  2. Calculate number of full groups: floor(total / k)
  3. For each group, reverse k nodes
  4. Connect each reversed group to the previous one
  5. Leave remaining nodes (less than k) as-is
const totalElements = this.countElements(head); const subsetTotal = Math.floor(totalElements / k); for (let count = 0; count < subsetTotal; count++) { const [pv, nh] = this.reverseSubset(start, k - 1, tail); if (prevPtr) prevPtr.next = nh; prevPtr = pv; if (iterations === 0) { retHead = nh; iterations++; } start = tail; } return retHead;

Approach Comparison

Iterative O(n) O(1) No recursion, constant space More complex pointer manipulation
