Merge k Sorted Lists

LeetCode 23 — Merge k sorted linked lists into one

Linked List Divide and Conquer Heap

Problem Overview

Given k sorted linked lists, merge them into one sorted linked list.

Input: lists = [[1,4,5],[1,3,4],[2,6]] Output: [1,1,2,3,4,4,5,6]

Approach 1: Collect All Values and Sort

Intuition: Extract all values, sort, rebuild list.

Time: O(N log N) Space: O(N)
Collect all values, sort, rebuild
[1,4,5] + [1,3,4] + [2,6] = [1,4,5,1,3,4,2,6]
Sort: [1,1,2,3,4,4,5,6]
Rebuild: 1->1->2->3->4->4->5->6

Doesn't leverage the fact that input lists are already sorted.

Approach 2: Iterative Min Selection (Implemented)

Intuition: At each step, pick the smallest head among all lists.

Time: O(k * N) Space: O(1)
Input lists
List 0:
1→ 4→ 5
List 1:
1→ 3→ 4
List 2:
2→ 6
Step-by-step merge
Heads: [1, 1, 2] -> min=1 (list 0)
Heads: [4, 1, 2] -> min=1 (list 1)
Heads: [4, 3, 2] -> min=2 (list 2)
Heads: [4, 3, 6] -> min=3 (list 1)
Heads: [4, 4, 6] -> min=4 (list 0)
Heads: [5, 4, 6] -> min=4 (list 1)
Heads: [5, Inf, 6] -> min=5 (list 0)
Heads: [Inf, Inf, 6] -> min=6 (list 2)
Result
1→ 1→ 2→ 3→ 4→ 4→ 5→ 6
Normal node
Minimum head (selected)
Result node
  1. Create dummy head node
  2. Map all list heads to values (Infinity for null)
  3. Find minimum value and its list index
  4. If all Infinity, break
  5. Append min node to result, advance that list
  6. Repeat until all lists exhausted
const newNode = new ListNode(); let curr = newNode; while (true) { const values = lists.map(list => list?.val ?? Infinity); const minValue = Math.min(...values); if (minValue === Infinity) break; const minIndex = values.indexOf(minValue); curr.next = lists[minIndex]; lists[minIndex] = lists[minIndex].next; curr = curr.next; } return newNode.next;

Approach Comparison

Approach Time Space Pros Cons
Collect & Sort O(N log N) O(N) Simple Doesn't leverage sorted input
Min Selection O(k * N) O(1) No extra space O(k) per step
Min-Heap O(N log k) O(k) Optimal time Requires heap
