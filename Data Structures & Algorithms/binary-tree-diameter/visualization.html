Binary Tree Diameter

LeetCode 543 — Find the longest path between any two nodes

Tree DFS Binary Tree

Problem Overview

The diameter of a binary tree is the length of the longest path between any two nodes, measured in edges. The path may or may not pass through the root.

Input: root = [1,2,3,4,5] Output: 3 (path: 4 → 2 → 1 → 3)

Approach 1: Brute Force (For Each Node)

Intuition: For every node, compute left and right subtree heights separately and track the maximum sum.

Time: O(n^2) Space: O(h)
Recompute height for every node
Node 1: height(left)=2, height(right)=1, d=3
Node 2: height(left)=1, height(right)=1, d=2
Node 3: height(left)=0, height(right)=0, d=0

O(n^2) because height() is called for every node.

Approach 2: DFS with Global Maximum (Optimal)

Intuition: Compute height and update diameter in a single DFS pass.

Time: O(n) Space: O(h)
Tree: [1,2,3,4,5]
DFS traversal (post-order)
Node 4: L=0, R=0, maxLen=0, return 1
Node 5: L=0, R=0, maxLen=0, return 1
Node 2: L=1, R=1, maxLen=2, return 2
Node 3: L=0, R=0, maxLen=2, return 1
Node 1: L=2, R=1, maxLen=3, return 3
Diameter = 3 (path: 4 → 2 → 1 → 3)
Normal node
Diameter path
Active node
  1. Initialize maxLength = 0
  2. DFS: if node is null, return 0
  3. Recursively get left and right subtree heights
  4. Update maxLength = max(maxLength, left + right)
  5. Return max(left, right) + 1 as subtree height
  6. After DFS, maxLength holds the diameter
let maxLength = 0; const findDiameter = (node) => { if (node === null) return 0; const left = findDiameter(node.left); const right = findDiameter(node.right); maxLength = Math.max(maxLength, left + right); return Math.max(left, right) + 1; }; findDiameter(root); return maxLength;

Approach Comparison

Approach Time Space Pros Cons
Brute Force O(n^2) O(h) Simple concept Recomputes heights repeatedly
DFS with Global Max O(n) O(h) Single pass, optimal Requires global variable
