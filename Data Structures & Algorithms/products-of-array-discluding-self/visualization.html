Product of Array Except Self

LeetCode 238

Array Prefix Sum

Problem Overview

Given an integer array nums, return an array where answer[i] is the product of all elements except nums[i].

Input: nums = [1, 2, 3, 4] Output: [24, 12, 8, 6] Input: nums = [-1, 1, 0, -3, 3] Output: [0, 0, 9, 0, 0]

Approach 1: Brute Force

O(n²)

For each index i, iterate through the entire array and multiply all elements where j ≠ i.

Time: O(n²) Space: O(1)

Brute Force: nums = [1, 2, 3, 4]

i=0 2 × 3 × 4 = 24
i=1 1 × 3 × 4 = 12
i=2 1 × 2 × 4 = 8
i=3 1 × 2 × 3 = 6
For each i, skip nums[i] and multiply the rest

Approach 2: Division

O(n) — fails with zeros

Calculate total product, then result[i] = totalProduct / nums[i].

Time: O(n) Space: O(1)

Fails if the array contains zero (division by zero). Not allowed per problem constraints.

Approach 3: Prefix and Suffix Products

Optimal — O(n)

For each index, the answer is: (product of all elements to the LEFT) × (product of all elements to the RIGHT). Compute in two passes.

Time: O(n) Space: O(1) extra

const n = nums.length; const result = new Array(n).fill(1); let prefix = 1; for (let i = 0; i < n; i++) { result[i] = prefix; prefix *= nums[i]; } let suffix = 1; for (let i = n - 1; i >= 0; i--) { result[i] *= suffix; suffix *= nums[i]; } return result;

Approach Comparison

Approach Time Space Notes
Brute Force O(n²) O(1) Too slow for large inputs
Division O(n) O(1) Fails if array contains zero
Prefix/Suffix O(n) O(1) Handles zeros, no division needed
