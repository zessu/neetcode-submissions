Valid Parentheses

LeetCode 20 — Easy

String Stack

Problem Overview

Given a string s containing only (, ), {, }, [, and ], determine if the string is valid.

Validity Rules

  • Open brackets must be closed by the same type of bracket
  • Open brackets must be closed in the correct order (LIFO)

Bracket Pairs

( ↔ )
{ ↔ }
[ ↔ ]

Examples

Approach 1: String Replacement (Brute Force)

Repeatedly replace matching pairs with empty string until no more replacements can be made.

Visual: Replacement Process

"()[]{}"
Replace "()" → "[]{}"
Replace "[]" → "{}"
Replace "{}" → ""
Empty string → valid

Code

while (s.includes("()") || s.includes("[]") || s.includes("{}")) { s = s.replace("()", "").replace("[]", "").replace("{}", ""); } return s.length === 0;

Time: O(n²)  |  Space: O(n)

Approach 2: Stack (Optimal)

Push opening brackets onto a stack. When a closing bracket is encountered, pop and compare.

Algorithm

  • If opening bracket → push onto stack
  • If closing bracket → pop from stack and check if it matches
  • At end: stack must be empty for valid string

Code

const matchingPairs = { "}": "{", ")": "(", "]": "[" }; const stack = []; if (s.length % 2) return false; for (const bracket of s) { if ("({[".includes(bracket)) { stack.push(bracket); } else { const top = stack.pop(); if (matchingPairs[bracket] !== top) return false; } } return stack.length === 0;

Time: O(n)  |  Space: O(n)
