Sum of All Subset XOR Totals

LeetCode 1863 — Sum the XOR of every one of the 2n subsets

Recursion Bit Manipulation Combinatorics

Problem Overview

For every subset of nums, compute the bitwise XOR of its elements (the empty subset has XOR 0). Return the sum of all those XOR values.

Input: nums = [1, 3] Output: 6 // subsets: 0, 1, 3, 2 -> sum = 6 Input: nums = [5, 1, 6] Output: 28 // subsets: 0, 5, 1, 6, 4, 3, 7, 2 Input: nums = [3, 4, 5, 6, 7, 8] Output: 480 // OR = 15, then 15 * 2^5 = 480

With n <= 12, there are at most 4096 subsets, so enumeration is feasible. A bit-level argument gives an O(n) formula as well.

Approach 1: Enumerate Subsets with a Bitmask

Intuition: Each subset is an n-bit number. Bit j set means nums[j] is included. Loop over all masks and XOR the selected elements.

Time: O(n · 2n) Space: O(1)

let total = 0; for (let mask = 0; mask < (1 << n); mask++) { let xor = 0; for (let j = 0; j < n; j++) { if (mask & (1 << j)) xor ^= nums[j]; } total += xor; } return total;

This is a useful independent correctness check for the recursive version, but it does an extra O(n) scan per subset.

Approach 2: Include/Exclude DFS (Implemented)

Intuition: Walk the array once. At index i, either skip nums[i] or XOR it into the running total. Each root-to-leaf path is one subset, and the sum of all leaves is the answer.

Time: O(2n) Space: O(n)
Subset decision tree for nums = [1, 3] — green leaves are the final XOR totals
root call partial subset completed subset

Each internal node returns the sum of its two children, so the root returns 0 + 3 + 1 + 2 = 6 with no accumulator needed.

const recurr = (i, total) => { if (i === nums.length) return total; return recurr(i + 1, total) // exclude nums[i] + recurr(i + 1, total ^ nums[i]); // include nums[i] }; return recurr(0, 0);
Why this is O(2n): the recursion tree is a full binary tree of depth n. It has exactly 2n leaves (one per subset) and 2n+1 - 1 nodes, and each node does constant work.

Approach 3: The Bitwise OR Shortcut

Intuition: Consider one bit at a time. If no element has bit b set, bit b is 0 in every subset XOR. If at least one element has bit b set, exactly half of the subsets produce a 1 in that position.

Time: O(n) Space: O(1)
Why half the subsets have each present bit set

Pick one element x that has bit b. Fix the inclusion of every other element (2n-1 ways). For each fixed choice, flipping x in or out toggles bit b in the XOR. So the subsets pair up: exactly one of each pair has bit b set.
