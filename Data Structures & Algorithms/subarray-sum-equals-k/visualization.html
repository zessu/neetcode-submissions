Subarray Sum Equals K

LeetCode 560 — Count contiguous subarrays with sum k

Array Hash Table Prefix Sum O(n)

Problem Overview

Count how many contiguous, non-empty subarrays of nums sum to exactly k. Values can be negative or zero, so the running sum is not monotonic and a sliding window is unsafe.

Input: nums = [1,1,1], k = 2 Output: 2 ([0..1] and [1..2]) Input: nums = [1,2,3], k = 3 Output: 2 ([1,2] and [3])

Approach 1: Brute Force (O(n³) baseline, O(n²) running sum)

Intuition: Fix a start index and extend the end index one element at a time, adding the new element to a running sum. Every subarray is examined exactly once. Recomputing each sum from scratch would add a third loop.

Approach 2: Prefix Sum Array

Intuition: Precompute P[i] = sum of the first i elements, with P[0] = 0. A subarray nums[i..j-1] sums to P[j] - P[i]. Check every pair of prefix positions.

The identity P[j] - P[i] = k is the key. The hash map replaces the inner scan with a lookup of P[j] - k.

Approach 3: Prefix Sum + Hash Map (Implemented)

Intuition: While scanning once, remember how many times each prefix sum has appeared. At the current prefix sum, every earlier prefix equal to sum - k closes a valid subarray. Add its frequency to the answer.

Approach 4: Sliding Window — Why It Fails

Intuition (misleading): Grow the window until its sum reaches k, then shrink from the left. This works only when all values are non-negative and the sum moves monotonically.

Key Insights & Pitfalls

Key insight: a subarray sum is a difference of two prefix sums. Instead of searching for P[i] such that P[j] - P[i] = k, look up P[j] - k in a frequency map of earlier prefixes.
Pitfall 1: Forget map.set(0, 1) and every subarray starting at index 0 disappears from the count.
Pitfall 2: Update the map after the lookup. Otherwise the current prefix can pair with itself, counting an empty subarray.
Pitfall 3: Use a map of counts, not a set. Repeated prefix sums (from negative numbers or zeroes) each represent different valid starts.
Pitfall 4: Do not use a sliding window. Negative values destroy monotonicity, so a valid subarray can be skipped forever.
Pitfall 5: The answer is a count, not a list of subarrays. Return the integer.
