Search in Rotated Sorted Array

LeetCode 33 — Find the index of a target in a rotated sorted array in O(log n) time.

Array Binary Search

Problem Overview

Given a sorted array that may have been rotated at an unknown pivot, find the index of a target value. Return -1 if not found. Must run in O(log n).

Input: nums = [4, 5, 6, 7, 0, 1, 2], target = 0 Output: 4

The key insight: at every binary search step, at least one half of the array is guaranteed to be sorted. We check if the target lies within the sorted half.

Approach 2: Modified Binary Search (Optimal)

Identify Sorted Half, Then Search

At each step, determine which half is sorted. If the target is within the sorted half's range, search there; otherwise search the other half.
