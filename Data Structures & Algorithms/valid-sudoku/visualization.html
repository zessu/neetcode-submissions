Problem Overview

Determine if a 9×9 Sudoku board is valid. Only filled cells need to be validated according to three rules.

Three Validation Rules

Rows

Each row must have digits 1-9 without repetition

Columns

Each column must have digits 1-9 without repetition

3×3 Boxes

Each 3×3 sub-box must have digits 1-9 without repetition

Approach 1: Brute Force

For every filled cell, scan its entire row, column, and 3×3 box to check for duplicates.

  • For each cell (r, c) with a value, scan all 9 cells in row r
  • Scan all 9 cells in column c
  • Scan all 9 cells in the 3×3 box containing (r, c)
  • If any duplicate found, return false

Time: O(n³) where n=9  |  Space: O(1)

Approach 2: Three-Pass Scan (Implemented)

Validate rows, then columns, then 3×3 boxes in three separate passes using hash maps to detect duplicates.

Visual: Three Validation Passes

Pass 1: Rows
Pass 2: Columns
Pass 3: 3×3 Boxes

Row Validation

for (const item in board) { const rowVals = new Map(); for (let i = 0; i < 9; i++) { const current = board[item][i]; if (rowVals.has(current) && current !== ".") return false; rowVals.set(current, 1); } }

Column Validation

for (const item in board) { const colVals = new Map(); for (let i = 0; i < 9; i++) { const current = board[i][item]; if (colVals.has(current) && current !== ".") return false; colVals.set(current, 1); } }

3×3 Box Validation

for (let i = 0; i < 9; i += 3) { for (let j = 0; j < 9; j += 3) { const gridVals = new Map(); for (let r = i; r < i + 3; r++) { for (let c = j; c < j + 3; c++) { const current = board[r][c]; if (gridVals.has(current) && current !== ".") return false; gridVals.set(current, 1); } } } }

Time: O(81) = O(1)  |  Space: O(1)

Approach 3: Single-Pass Hash Set

Use three arrays of sets (for rows, columns, and boxes) and validate everything in a single pass through the board.

Visual: Box Index Formula

boxIndex = Math.floor(row / 3) * 3 + Math.floor(col / 3)
const rows = Array.from({length: 9}, () => new Set()); const cols = Array.from({length: 9}, () => new Set()); const boxes = Array.from({length: 9}, () => new Set()); for (let r = 0; r < 9; r++) { for (let c = 0; c < 9; c++) { const val = board[r][c]; if (val === '.') continue; const boxIdx = Math.floor(r / 3) * 3 + Math.floor(c / 3); if (rows[r].has(val) || cols[c].has(val) || boxes[boxIdx].has(val)) return false; rows[r].add(val); cols[c].add(val); boxes[boxIdx].add(val); } }

Time: O(81) = O(1)  |  Space: O(81) = O(1)

Comparison

Approach Time Space Notes
Brute Force O(n³) O(1) Triple scan for every cell
Three-Pass Scan O(1) O(1) Readable, check rows/cols/boxes separately
Single-Pass Hash O(1) O(1) All three checks in one loop
