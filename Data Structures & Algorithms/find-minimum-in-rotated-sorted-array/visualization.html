Find Minimum in Rotated Sorted Array

LeetCode 153 — Find the minimum element in a rotated sorted array.

Array Binary Search

Problem Overview

Given a sorted array that has been rotated between 1 and n times, find the minimum element. The array was originally sorted in ascending order before rotation.

Input: nums = [4, 5, 6, 7, 0, 1, 2] Output: 0

The key insight is that the minimum element sits at the "pivot point" where the rotation wraps around. In a non-rotated array, the minimum is simply the first element.

Find the Pivot Point
