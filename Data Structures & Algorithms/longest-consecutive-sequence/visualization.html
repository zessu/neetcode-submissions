Longest Consecutive Sequence

LeetCode 128 — Find the length of the longest consecutive elements sequence in an unsorted array in O(n) time.

Array Hash Table Union Find

Problem Overview

Given an unsorted array, find the length of the longest sequence of consecutive integers.

Input: nums = [100, 4, 200, 1, 3, 2] Output: 4 (sequence: 1, 2, 3, 4)

Approach 1: Brute Force

Check Every Number as a Potential Start

For each number, scan the entire array to check if the next consecutive number exists.

For each num, linearly search for num+1, num+2, ...
100
→ search for 101? No. Length = 1
1
→ search for 2? Yes → 3? Yes → 4? Yes → 5? No. Length = 4

Time: O(n³)  |  Space: O(1)

Approach 2: Sorting

Sort, Then Count Consecutive

Sort the array and iterate through to find the longest run of consecutive numbers.

Sort and remove duplicates

2
3
4
100
200
1→ 2→ 3→ 4 length = 4

Time: O(n log n)  |  Space: O(1) or O(n)

Approach 3: HashSet (Optimal)

Only Start Counting from Sequence Beginnings

Put all numbers in a set. For each number, only start counting if num - 1 is NOT in the set (meaning it's the start of a sequence).

Build set: {100, 4, 200, 1, 3, 2}
Check 100: has 99? No → sequence start
100
→ has 101? No. Length = 1
Check 4: has 3? Yes → NOT a start (skip)
4
→ skip
Check 200: has 199? No → sequence start
200
→ has 201? No. Length = 1
Check 1: has 0? No → sequence start!
1→ 2→ 3→ 4→ 5? length = 4
numSet = new Set(nums) longest = 0 for num of nums: if !numSet.has(num - 1): // sequence start length = 0 while numSet.has(num + length): length++ longest = max(longest, length) return longest

Time: O(n)  |  Space: O(n)
