Maximum Depth of Binary Tree

LeetCode 104 — Find the longest path from root to leaf

Tree DFS BFS

Problem Overview

The maximum depth is the number of nodes along the longest path from the root to the farthest leaf.

Input: root = [3,9,20,null,null,15,7] Output: 3 (path: 3 → 20 → 15 or 3 → 20 → 7)

Approach 1: BFS (Level Order)

Intuition: Traverse level by level, counting levels.

Time: O(n) Space: O(w)
Level-by-level traversal
Level 1: [3]
Level 2: [9, 20]
Level 3: [15, 7]
Depth = 3

Approach 2: Recursive DFS (Optimal)

Intuition: Depth = 1 + max(left depth, right depth).

Time: O(n) Space: O(h)
Tree: [3,9,20,null,null,15,7]
Recursive computation
maxDepth(9) = 1 + max(0, 0) = 1
maxDepth(15) = 1 + max(0, 0) = 1
maxDepth(7) = 1 + max(0, 0) = 1
maxDepth(20) = 1 + max(1, 1) = 2
maxDepth(3) = 1 + max(1, 2) = 3
Level 1
Level 2
Level 3
  1. If node is null, return 0
  2. Recursively compute left subtree depth
  3. Recursively compute right subtree depth
  4. Return 1 + max(left, right)
maxDepth(root) { if (root === null) return 0; return Math.max( this.maxDepth(root.left), this.maxDepth(root.right) ) + 1; }

Approach Comparison

Approach Time Space Pros Cons
BFS O(n) O(w) Iterative, no stack overflow Uses queue, more code
Recursive DFS O(n) O(h) Elegant, minimal code Stack overflow for skewed trees
