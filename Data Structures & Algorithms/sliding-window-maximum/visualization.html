Sliding Window Maximum

Array Sliding Window Monotonic Queue Heap LeetCode 239

Problem Overview

Given an array of integers and a sliding window of size k moving from left to right, return the maximum value in each window position.

nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3 Output: [3, 3, 5, 5, 6, 7]

Approach 2: Monotonic Deque (Optimal)

Time: O(n) Space: O(k)

Approach 3: Max Heap

Time: O(n log k) Space: O(k)

Use a max heap to track the maximum in the current window. Insert each element and lazily remove elements that fall outside the window.

Comparison

Approach Time Space Pros Cons
Brute Force O(n * k) O(1) Simple to implement TLE on large inputs
Monotonic Deque O(n) O(k) Optimal time More complex logic
Max Heap O(n log k) O(k) Moderate improvement Still slower than deque
