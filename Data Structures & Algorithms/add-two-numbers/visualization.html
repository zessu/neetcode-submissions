Add Two Numbers

LeetCode 2 — Add two numbers represented as reversed linked lists

Linked List Math

Problem Overview

Two non-empty linked lists represent non-negative integers in reverse order. Add them and return the sum as a linked list.

Input: l1 = [2,4,3], l2 = [5,6,4] Output: [7,0,8] (342 + 465 = 807)

Approach 1: Convert to Integers (Naive)

Intuition: Convert both lists to integers, add, then convert back.

Time: O(max(m, n)) Space: O(max(m, n))
Steps
l1 = [2,4,3] → 342
l2 = [5,6,4] → 465
342 + 465 = 807 → [7,0,8]

Fails for numbers exceeding 64-bit integer range.

Approach 2: Elementary Math (Optimal)

Intuition: Add digit by digit with carry, like elementary school addition.

Time: O(max(m, n)) Space: O(max(m, n))
Input lists: l1 = [2,4,3], l2 = [5,6,4]
2→ 4→ 3
5→ 6→ 4
Step-by-step addition

Step 1: 2 + 5 + carry(0) = 7

digit = 7 % 10 = 7 → carry = 0
7

Step 2: 4 + 6 + carry(0) = 10

digit = 10 % 10 = 0 → carry = 1
7→ 0

Step 3: 3 + 4 + carry(1) = 8

digit = 8 % 10 = 8 → carry = 0
7→ 0→ 8
Result: [7, 0, 8] (represents 807)
Input node
Carry generated
Result node
  1. Initialize ptr1 = l1, ptr2 = l2, carry = 0
  2. While ptr1 or ptr2 exists: sum = (ptr1?.val || 0) + (ptr2?.val || 0) + carry
  3. Create new node with value sum % 10
  4. Update carry = Math.floor(sum / 10)
  5. Advance ptr1 and ptr2
  6. If carry > 0 after loop, append final node
let ptr1 = l1, ptr2 = l2, rem = 0; let finalList = null, dirty = false; while (ptr1 || ptr2) { if (!ptr1) ptr1 = { val: 0, next: null }; if (!ptr2) ptr2 = { val: 0, next: null }; const sum = ptr1.val + ptr2.val + rem; rem = sum >= 10 ? 1 : 0; const newNode = { val: sum % 10, next: null }; if (!dirty) { finalList = newNode; dirty = true; } else { appendNode(finalList, newNode); } ptr1 = ptr1.next; ptr2 = ptr2.next; } if (rem) appendNode(finalList, { val: 1, next: null }); return finalList;
