Minimum Window Substring

LeetCode 76

String Sliding Window Hash Table Two Pointers

Problem Overview

Given strings s and t, find the minimum window substring of s that contains all characters of t (including duplicates).

Input: s = "ADOBECODEBANC", t = "ABC" Output: "BANC" Explanation: "BANC" contains A, B, and C — the shortest such window.

Approach 1: Brute Force

O(n³)

For every (i, j) pair, check if s[i..j] contains all characters of t. Track the shortest valid substring.

Time: O(n³) Space: O(σ)

Impractical for n = 105.

Approach 2: Sliding Window with Rebuilt Maps

O(n² · σ)

Expand right until the window contains all of t, then shrink left while it still does. The window's frequency map is rebuilt from scratch each step.

Time: O(n² · σ) worst case Space: O(σ)

Approach 3: Sliding Window with have/need Counters

Optimal — O(n)

Maintain the window's frequency map incrementally. Track have (characters meeting quota) and need (unique chars in t). Window is valid when have === need.

Time: O(n + σ) Space: O(σ)

have/need Counter Walkthrough

t = "ABC" → need = 3 unique characters

r=0 'A' window A:1 meets need → have=1
r=1 'D' not required, have=1
r=3 'B' window B:1 meets need → have=2
r=5 'C' window C:1 meets need → have=3 = need!
Shrink l=0 'A' leaves → A:0 < 1 → have=2, l=1
... continue until "BANC" found as shortest
have: 3 need: 3

When have === need, the window is valid → try shrinking.

const need = new Map(); for (const c of t) need.set(c, (need.get(c) || 0) + 1); const window = new Map(); let have = 0, needSize = need.size; let l = 0, resLen = Infinity, res = ""; for (let r = 0; r < s.length; r++) { window.set(s[r], (window.get(s[r]) || 0) + 1); if (need.has(s[r]) && window.get(s[r]) === need.get(s[r])) have++; while (have === needSize) { if (r - l + 1 < resLen) { resLen = r - l + 1; res = s.substring(l, r + 1); } window.set(s[l], window.get(s[l]) - 1); if (need.has(s[l]) && window.get(s[l]) < need.get(s[l])) have--; l++; } } return res;
