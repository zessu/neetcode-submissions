Longest Palindromic Substring

LeetCode 5 — Expand around every possible center

String Two Pointers Expand Around Center Dynamic Programming

Problem Overview

Find the longest contiguous substring of s that reads the same forwards and backwards. Any one of the longest answers is accepted.

Input: s = "babad" Output: "bab" // "aba" is also valid Input: s = "cbbd" Output: "bb" Input: s = "a" Output: "a"

A palindrome is fixed by its center: every matching pair expands outward symmetrically. There are 2n - 1 centers for a string of length n.

Approach 1: Brute Force

Intuition: Enumerate all substrings, check each one for palindromicity, and keep the longest.

Time: O(n³) Space: O(1)
s = "babad" — check every start/end pair
"b"→palindrome, length 1
"ba"→not a palindrome
"bab"→palindrome, length 3 ✓
"baba"→not a palindrome
"babad"→not a palindrome

There are O(n²) substrings, and checking each one costs O(n), so the total is O(n³).

Approach 2: Interval Dynamic Programming

Intuition: s[i..j] is a palindrome when the outer characters match and the inner substring s[i+1..j-1] is also a palindrome.

Time: O(n²) Space: O(n²)
Fill intervals by increasing length
length 1 dp[i][i] = true
length 2 "bb" → s[i] === s[j] and inner interval is empty → true
length 3 "bab" → 'b' === 'b' and dp[i+1][j-1] = "a" is true → true
length 4 "baba" → 'b' !== 'a' → false

The table stores about one million booleans when n = 1000.

Approach 4: Manacher's Algorithm

Intuition: Insert separators so every palindrome becomes odd-length, then reuse the symmetry of the rightmost palindrome to skip redundant comparisons.

Time: O(n) Space: O(n)
Transform "aba" into "#a#b#a#"
aba
#a#b#a#

Every center is now a single index, and the radius maps directly back to an original substring. The mirror rule lets each position start with a known radius instead of zero.
