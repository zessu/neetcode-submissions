Binary Tree Preorder Traversal

LeetCode 144 — node → left → right

Tree DFS Stack Binary Tree

Problem Overview

Return the values of a binary tree in preorder: record the node first, then fully explore the left subtree, then the right subtree. The root is always the first value in the output.

Input: root = [1, null, 2, 3] 1 \ 2 / 3 Output: [1, 2, 3] 1 is recorded immediately, then its right subtree: 2, then 3.

Approach 1: Recursive DFS (Implemented)

Intuition: Append the node on entry, then recurse left and right. The moment a node is reached is exactly when preorder wants it.

Time: O(n) Space: O(h)
Emission order on root = [1, null, 2, 3]

The null left child of 1 is skipped. Descent goes right to 2, then left to 3.

Recursive call flow
traverse(1): emit 1→ left = null→ traverse(2): emit 2→ traverse(3): emit 3
result = [1, 2, 3]

Approach 2: Explicit Stack

Intuition: Pop and visit a node, then push its children. Pushing right first, left second makes the left child pop next, preserving node → left → right.

Time: O(n) Space: O(h)
Stack states for root = [1, null, 2, 3]
start 1 Push the root.
pop 1 2 Output 1. Left is null; push right child 2.
pop 2 3 Output 2. Right is null; push left child 3.
pop 3 empty Output 3. No children; the stack empties.
output = [1, 2, 3]
const stack = [root]; while (stack.length) { const node = stack.pop(); result.push(node.val); if (node.right) stack.push(node.right); // right first if (node.left) stack.push(node.left); // left pops next }

Approach 3: Morris Traversal (O(1) Space)

Intuition: For a node with a left subtree, find the rightmost node of that subtree and temporarily point its empty right pointer back to the current node. That thread lets the walk return without a stack. Preorder is emitted before descending, so recording happens when the thread is created.

Time: O(n) Space: O(1)

After returning to 1 through the thread, it is removed (2.right = null) and the walk continues to 3. The tree is restored exactly as it was.

  1. curr = 1: left child 2 exists. The rightmost node of that subtree is 2, whose right is null, so thread 2.right = 1. Emit 1, then move left.
  2. curr = 2: no left child. Emit 2, then follow right to 1 (the thread).
  3. curr = 1: the thread is detected (2.right === 1). Remove it, then move right to 3.
  4. curr = 3: no left child. Emit 3, move right to null and stop.

Approach Comparison

Approach Time Space Pros Cons
Recursive DFS (implemented) O(n) O(h) Shortest, clearest code Stack overflow on deep trees
Explicit Stack O(n) O(h) Iterative, standard answer Must push right before left
Morris Traversal O(n) O(1) Constant auxiliary memory Mutates pointers temporarily; subtle

Key Insight & Common Pitfalls

Key insight: preorder emits on entry, so the root comes first and each subtree is a contiguous block: root + preorder(left) + preorder(right).
Pitfall: pushing left before right reverses the children and yields node → right → left.
Pitfall: a queue gives level order, not preorder. For [1,2,3,4,5,6,7], BFS returns [1,2,3,4,5,6,7] while preorder returns [1,2,4,5,3,6,7].
Pitfall: Morris must remove every thread. Forgetting pred.right = null leaves the tree corrupted and loops forever.
Pitfall: the submission stores res on the instance; reuse of one Solution object across calls would keep old values.
