Merge Sorted Array

LeetCode 88 — Merge two sorted arrays into nums1 in place

Array Two Pointers Sorting

Problem Overview

nums1 has length m + n: the first m cells hold sorted data, the last n are placeholders. nums2 holds n sorted values. Merge them so that nums1 becomes fully sorted, without returning a new array.

Input: nums1 = [1,2,3,0,0,0], m = 3 nums2 = [2,5,6], n = 3 ^ ^ real data placeholders Output: nums1 = [1,2,2,3,5,6] (mutated in place)

The copy touches only placeholder cells, so the first m values are preserved. The sort then fixes the interleaving — but it discards the information that both halves were already sorted.

Comparator required: nums1.sort() without a comparator sorts by string. [1,2,3,6,5,2] happens to survive, but [10,9,100] would become [10,100,9] and negatives would be ordered as -1, -3, -5.

Approach Time Space Uses sorted inputs? Notes

Common Pitfalls

  1. Forward merge overwrites unread data. Writing nums1[0] while nums1[1..m-1] is still unread destroys the input. Merge backward or use a buffer.
  2. Default sort is lexicographic. Always pass (a, b) => a - b; otherwise 10 sorts before 9.
  3. Placeholders are not values. The trailing zeros must never be compared or counted as data.
  4. m = 0. There is no real prefix; the answer is all of nums2. Copying into the single placeholder handles it.
  5. n = 0. The copy loop must not run, and the sort must leave nums1 untouched.
  6. Copy loop indexing. nums1[nums1.length - (count + 1)] walks the tail from the end. An off-by-one here either skips the first nums2 value or writes past the array.
  7. Returning a new array. The judge reads the mutated nums1; the method should return nothing.
