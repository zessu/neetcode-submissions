Largest Rectangle in Histogram

LeetCode 84 — Find the area of the largest rectangle that can be formed within a histogram.

Array Stack Monotonic Stack

Problem Overview

Given an array of bar heights (each with width 1), return the maximum rectangular area possible.

Input: heights = [2, 1, 5, 6, 2, 3] Output: 10 (width=2, height=5, using bars at index 2-3)

Approach 1: Brute Force

Expand Left and Right for Each Bar

For each bar, find how far left and right it can extend (while bars are at least as tall), then compute area.

Example: bar at index 2 (height=5)

Can extend right to index 3 (height 6 ≥ 5). Cannot extend left (height 1 < 5). Width = 2, area = 5 × 2 = 10.

Time: O(n²)  |  Space: O(1)

Approach 2: Monotonic Stack (Optimal)

Increasing Stack with Area Calculation on Pop

Maintain a stack of indices in increasing height order. When a shorter bar is encountered, pop and calculate the area using the popped height.

i=0: Push index 0 (height 2)
Stack:0 (h=2)
i=1: h=1 < 2 → Pop 0, area = 2 × 1 = 2. Push 1
Stack:1 (h=1)
i=2,3: Push (heights increasing)
Stack:1 (h=1)2 (h=5)3 (h=6)
i=4: h=2 < 6 → Pop 3, area = 6 × 1 = 6
Stack:1 (h=1)2 (h=5)

h=2 < 5 → Pop 2, area = 5 × (4-1-1) = 5 × 2 = 10

Stack:1 (h=1)4 (h=2)
i=5: Push 5 (height 3)
Stack:1 (h=1)4 (h=2)5 (h=3)
i=6 (sentinel h=0): Flush remaining

Pop 5: area = 3 × 1 = 3. Pop 4: area = 2 × 4 = 8. Pop 1: area = 1 × 6 = 6.

maxArea = 10

stack = [] maxArea = 0 for i = 0 to heights.length: h = (i === length) ? 0 : heights[i] while stack not empty && h < heights[stack.top()]: height = heights[stack.pop()] width = stack empty ? i : i - stack.top() - 1 maxArea = max(maxArea, height * width) stack.push(i) return maxArea

Time: O(n)  |  Space: O(n)
