Evaluate Reverse Polish Notation

LeetCode 150 — Evaluate an arithmetic expression in RPN

Array Stack Math

Problem Overview

Given an array of tokens representing an expression in Reverse Polish Notation, evaluate and return the result. Valid operators are +, -, *, /. Division truncates toward zero.

Input: tokens = ["2", "1", "+", "3", "*"] Output: 9 Explanation: ((2 + 1) * 3) = 9

Approach 1: Stack (Iterative)

Intuition: RPN is designed for stack evaluation. Push numbers; when an operator appears, pop two operands, apply the operation, push the result.

Time: O(n) Space: O(n)
Token-by-token evaluation: ["2", "1", "+", "3", "*"]

  1. Initialize an empty stack
  2. For each token: if number, push to stack
  3. If operator: pop two operands (b then a), compute a op b, push result
  4. Return the final element on the stack
const stack = []; for (const token of tokens) { if (isNumber(token)) { stack.push(parseInt(token)); } else { const b = stack.pop(); const a = stack.pop(); stack.push(apply(a, token, b)); } } return stack.pop();

Approach 2: Recursion (Functional)

Intuition: RPN can be viewed as a post-order traversal of an expression tree. Evaluate recursively from right to left.

Time: O(n) Space: O(n) stack
Expression tree for ((2 + 1) * 3)
*
/ \
+ 3
/ \
2 1

Post-order traversal: 2, 1, +, 3, * — exactly the RPN tokens

function evaluate(tokens) { const token = tokens.pop(); if (isNumber(token)) return parseInt(token); const right = evaluate(tokens); const left = evaluate(tokens); return apply(left, token, right); }

Key: Operand Order Matters

For - and /, the first popped value is the right operand, the second is the left:

Stack: [..., a, b] (b is on top) Token: "-" Result: a - b (NOT b - a) Token: "/" Result: Math.trunc(a / b) (truncate toward zero)
