Copy List with Random Pointer

LeetCode 138 — Deep copy a linked list with random pointers

Hash Table Linked List

Problem Overview

Each node has a next pointer and a random pointer. Create a deep copy where all pointers in the new list point to new nodes, not originals.

Input: head = [[7,null],[7,1],[13,0],[10,1],[5,null]] Output: deep copy with same structure

Approach 1: Hash Map (Two Pass)

Intuition: Use a hash map to map original nodes to their clones.

Time: O(n) Space: O(n)
Pass 1: Create clones, Pass 2: Set pointers
map = { orig1: clone1, orig2: clone2, ... }
clone1.next = map[orig1.next]
clone1.random = map[orig1.random]

Simple but uses O(n) extra space for the hash map.

Approach 2: Interweaving Nodes (Optimal)

Intuition: Interleave clones with originals to avoid using a hash map.

Time: O(n) Space: O(1)
Original list
7→ 7→ 13→ 10→ 5
Pass 1: Interleave clones
7→ 7'→ 7→ 7'→ 13→ 13'→ 10→ 10'→ 5→ 5'
Pass 2: Set random pointers (clone.random = original.random.next)
7'.random = 7.random?.next = null
7'.random = 7.random?.next = 7'
13'.random = 13.random?.next = 7'
10'.random = 10.random?.next = 7'
5'.random = 5.random?.next = null
Pass 3: Separate lists
Original: 7 → 7 → 13 → 10 → 5
Clone: 7' → 7' → 13' → 10' → 5'
Original node
Clone node
Valid pointer set
  1. If head is null, return null
  2. Pass 1: For each node, insert clone right after it
  3. Pass 2: Set clone.random = original.random?.next ?? null
  4. Pass 3: Separate original and clone lists
  5. Return cloneHead
// Pass 1: Interleave while (curr) { const clone = { val: curr.val, next: null, random: null }; clone.next = curr.next; curr.next = clone; curr = clone.next; } // Pass 2: Set random curr = head; while (curr) { curr.next.random = curr.random?.next ?? null; curr = curr.next.next; } // Pass 3: Separate curr = head; cloneHead = curr.next; while (curr) { const clone = curr.next; curr.next = clone.next; clone.next = clone.next?.next ?? null; curr = curr.next; }

Approach Comparison

Approach Time Space Pros Cons
Hash Map O(n) O(n) Simple, two passes Extra O(n) space for map
Interweaving Nodes O(n) O(1) No extra space Modifies original list temporarily
