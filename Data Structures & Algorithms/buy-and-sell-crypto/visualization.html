Buy and Sell Crypto

LeetCode 121 — Best Time to Buy and Sell Stock

Array Two Pointers Sliding Window Dynamic Programming Greedy

Problem Overview

Given an array prices where prices[i] is the price on day i, find the maximum profit from one buy and one sell transaction. You must buy before you sell.

Input: prices = [7, 1, 5, 3, 6, 4] Output: 5 (buy at 1, sell at 6)

Approach 1: Brute Force

Intuition: Check every possible (buy, sell) pair and track the maximum profit.

Time: O(n²) Space: O(1)
Checking all pairs for prices = [7, 1, 5, 3, 6, 4]
buy=7, sell=1→-6
buy=1, sell=5→+4
buy=1, sell=6→+5 (max)
buy=3, sell=6→+3

Checks all n(n-1)/2 pairs — too slow for large inputs.

Approach 2: Two Pointers / Sliding Window (Optimal)

Intuition: Track the cheapest buy price seen so far. At each day, compute profit against that minimum. When a new lower price is found, update the buy pointer.

Time: O(n) Space: O(1)

L=1 R=2 5 > 1 → profit=4, max=4

L=1 R=4 6 > 1 → profit=5, max=5
L=1 R=5 4 > 1 → profit=3, max=5
  1. Set leftPtr = 0, rightPtr = 1, maxProfit = 0
  2. If prices[right] > prices[left], update maxProfit
  3. Else, a new valley found: leftPtr = rightPtr
  4. Advance rightPtr, repeat until end

Approach 3: Kadane's Algorithm (Max Subarray)

Intuition: Convert prices to daily differences. Maximum profit = maximum subarray sum of differences.

Time: O(n) Space: O(1)
Differences: d[i] = prices[i] - prices[i-1]
prices: [7, 1, 5, 3, 6, 4]
diffs: [-, -6, +4, -2, +3, -2]
Max subarray sum: -6 + 4 + (-2) + 3 = 5 → but Kadane skips -6, starts at +4: 4 + (-2) + 3 = 5

Approach Comparison

Approach Time Space Pros Cons
Brute Force O(n²) O(1) Trivial to write TLE for n ≥ 10&sup4;
Two Pointers O(n) O(1) Single pass, intuitive Slightly tricky leftPtr update
Kadane's O(n) O(1) Elegant DP perspective Less obvious from problem statement
