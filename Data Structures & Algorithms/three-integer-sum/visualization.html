3Sum (Three Integer Sum)

Array Two Pointers Sorting LeetCode 15

Problem Overview

Given an integer array, return all unique triplets [nums[i], nums[j], nums[k]] such that i != j != k and nums[i] + nums[j] + nums[k] == 0.

Input: [-1, 0, 1, 2, -1, -4] Output: [[-1, -1, 2], [-1, 0, 1]]

Approach 1: Brute Force

Time: O(n^3) Space: O(k)

Three nested loops to check all possible triplets. Use a set or map to avoid duplicates.

Approach 2: Hash Map (Two Sum Variation)

Time: O(n^2) Space: O(n)

Sort the array, then for each element, solve Two Sum for the remainder using a hash map.

Approach 3: Sort + Two Pointers (Optimal)

Time: O(n^2) Space: O(1)

Sort the array, fix one element, then use two pointers (left, right) to find pairs summing to the negative of the fixed element. Skip duplicates to avoid duplicate triplets.
