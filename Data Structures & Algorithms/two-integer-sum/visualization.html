Two Sum

LeetCode 1 — Easy

Array Hash Table

Problem Overview

Given an array of integers nums and an integer target, return the indices of the two numbers that add up to target.

Find i, j such that nums[i] + nums[j] == target

target = 9 → Output: [0, 1] because 2 + 7 = 9

Approach 1: Brute Force

Check every possible pair of numbers to see if they sum to the target.

Visual: Pair Checking

i →
Check all pairs (i, j) where j > i
← j
  • Outer loop: pick each element as first number
  • Inner loop: pick each subsequent element as second number
  • If nums[i] + nums[j] == target, return [i, j]

Code

for (let i = 0; i < nums.length; i++) { for (let j = i + 1; j < nums.length; j++) { if (nums[i] + nums[j] === target) { return [i, j]; } } }

Time: O(n²)  |  Space: O(1)

Approach 2: Sorting + Two Pointers

Sort the array and use two pointers from both ends. Requires tracking original indices.

Time: O(n log n)  |  Space: O(n)

Approach 3: Hash Map - One Pass (Optimal)

For each number, check if its complement (target - num) already exists in the hash map.

Visual: Hash Map Building

Step i=0: num=2, complement=7, map empty → store {2: 0}

Code

const map = new Map(); for (let i = 0; i < nums.length; i++) { const complement = target - nums[i]; if (map.has(complement)) { return [map.get(complement), i]; } map.set(nums[i], i); }

Time: O(n)  |  Space: O(n)

Comparison

Approach Time Space Notes
Brute Force O(n²) O(1) Simplest but slowest
Sorting + Two Pointers O(n log n) O(n) Requires tracking original indices
Hash Map O(n) O(n) Most efficient for unsorted arrays
