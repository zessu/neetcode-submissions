Container With Most Water

LeetCode 11

Array Two Pointers Greedy

Problem Overview

Given an array height of n non-negative integers, find two lines that together with the x-axis form a container that holds the most water.

Input: height = [1,8,6,2,5,4,8,3,7] Output: 49 Explanation: Lines at index 1 (height=8) and index 8 (height=7) Area = (8-1) × min(8,7) = 7 × 7 = 49

Approach 1: Brute Force

O(n²)

Check every possible pair of lines and calculate the water trapped between them.

Time: O(n²) Space: O(1)

Approach 2: Two Pointers

Optimal — O(n)

Start with pointers at both ends. Always move the pointer pointing to the shorter line inward. Width decreases each step, so we can only improve if the shorter side gets taller.

Time: O(n) Space: O(1)

Final Result: 49

let maxWater = 0; let left = 0, right = heights.length - 1; while (left < right) { const width = right - left; const height = Math.min(heights[left], heights[right]); maxWater = Math.max(maxWater, width * height); if (heights[left] < heights[right]) { left++; } else { right--; } } return maxWater;
