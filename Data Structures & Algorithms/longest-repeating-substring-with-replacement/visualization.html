Longest Repeating Character Replacement

LeetCode 424 — Find the longest substring of identical characters after at most k replacements.

String Sliding Window Hash Table

Problem Overview

Given a string s and integer k, you can replace at most k characters. Find the length of the longest substring with all identical characters.

Input: s = "AABABBA", k = 1 Output: 4 (replace B at index 2 → "AAAABBA", longest uniform = "AAAA")

Approach 1: Brute Force

Try Every Substring

For every (i, j) pair, count character frequencies and check if (windowLen - maxFreq) ≤ k.

Check all substrings

"A" → rep=0 ≤ 1 ✓

"AA" → rep=0 ≤ 1 ✓

"AAB" → rep=1 ≤ 1 ✓

"AABA" → rep=1 ≤ 1 ✓ (length 4)

"AABAB" → rep=2 > 1 ✗

... and so on for all O(n²) pairs

Time: O(n³)  |  Space: O(1)

Approach 2: Sliding Window (Optimal)

Expand Right, Shrink Left When Invalid

Maintain window [l, r] with a frequency map. If windowLen - maxFreq > k, shrink from the left.

r=0: "A" → {A:1}, maxFreq=1, rep=0 ≤ 1

count = new Array(26).fill(0) l = 0, maxFreq = 0, result = 0 for r = 0 to n-1: count[s[r] - 'A']++ maxFreq = max(maxFreq, count[s[r] - 'A']) while (r - l + 1) - maxFreq > k: count[s[l] - 'A']-- l++ result = max(result, r - l + 1) return result

Time: O(n)  |  Space: O(1)
