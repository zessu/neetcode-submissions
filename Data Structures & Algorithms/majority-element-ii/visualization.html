Majority Element II

LeetCode 229 — Find every value appearing more than ⌊n / 3⌋ times

Array Hash Table Counting Sorting Boyer-Moore

Problem Overview

Given nums of length n, return all elements whose frequency is strictly greater than n / 3. Order does not matter. Because three values cannot each take more than a third of the array, there are at most two answers.

Input: nums = [1,1,1,3,3,2,2,2] n = 8, n/3 = 2.67 -> a value needs count 3 or more Output: [1,2] (1 appears 3x, 2 appears 3x, 3 appears only 2x) Edge case: nums = [1,2] n = 2, floor(n/3) = 0 -> BOTH values qualify Output: [1,2]

Why two candidates? Three values each appearing more than n/3 times would need more than n elements in total. So a third candidate is never necessary — and each cancellation removes three distinct values, preserving the relative majorities of whatever remains.

Common Pitfalls

  1. Strict inequality. A value appearing exactly ⌊n/3⌋ times is not an answer. Use count > n/3 (equivalently count > Math.floor(n/3)).
  2. At most two answers, but possibly two. Do not return early after the first value crosses the threshold.
  3. Tiny arrays. When n ≤ 2, ⌊n/3⌋ = 0, so every distinct value qualifies: [1,2] → [1,2].
  4. Deduplicate results. The threshold is crossed once, but every later occurrence also satisfies it — use a set.
  5. Verify Boyer-Moore candidates. Cancellation can leave values that do not actually exceed n/3; a second counting pass is mandatory.
  6. Beware splice-style removal. Deleting while iterating shifts indices and skips elements; counting needs no mutation at all.
