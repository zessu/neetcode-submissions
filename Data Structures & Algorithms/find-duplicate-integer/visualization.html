Find the Duplicate Number

LeetCode 287 — Find the repeated number in an array

Array Hash Set Two Pointers

Problem Overview

Given an array of n+1 integers in range [1, n], find the single duplicate number without modifying the array and using O(1) extra space.

Input: nums = [1,3,4,2,2] Output: 2

Approach 1: Hash Set

Intuition: Track seen numbers; the first one already in the set is the duplicate.

Time: O(n) Space: O(n)
Array: [1, 3, 4, 2, 2]

i=4: nums[4]=2, already in set! Return 2

Approach 2: Floyd's Cycle Detection (Optimal)

Intuition: Treat array as linked list with cycle; find cycle entrance.

Time: O(n) Space: O(1)
Array as linked list: nums[i] points to index nums[i]
0 → 1 → 3 → 2 → 4 → 2 → 4 → ...

Cycle: 2 → 4 → 2. The entrance (2) is the duplicate.

Valid step
  1. Initialize an empty set
  2. Iterate through each number in the array
  3. If number is in set, return it as duplicate
  4. Otherwise, add number to set
const existing = new Set(); for (const num in nums) { if (existing.has(nums[num])) return nums[num]; existing.add(nums[num]); }

Approach Comparison

Approach Time Space Pros Cons
Hash Set O(n) O(n) Simple, one pass Uses O(n) extra space
Floyd's Cycle O(n) O(1) Constant space, no modification Harder to understand
Binary Search O(n log n) O(1) No modification, constant space Slower than O(n)
