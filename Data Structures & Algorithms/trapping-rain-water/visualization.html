Trapping Rain Water

LeetCode 42 — Hard

Array Two Pointers Dynamic Programming Stack Monotonic Stack

Problem Overview

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

water[i] = min(maxLeft[i], maxRight[i]) - height[i]

Approach 1: Brute Force

For each bar, scan left and right to find the maximum heights, then compute trapped water.

Algorithm Steps

  • For each index i, scan all elements to the left to find maxLeft
  • Scan all elements to the right to find maxRight
  • Add min(maxLeft, maxRight) - height[i] to total water
maxLeft scan ←
i
→ maxRight scan

Code

for (let i = 0; i < height.length; i++) { let maxLeft = 0, maxRight = 0; for (let j = 0; j < i; j++) maxLeft = Math.max(maxLeft, height[j]); for (let j = height.length - 1; j > i; j--) maxRight = Math.max(maxRight, height[j]); sum += Math.min(maxLeft, maxRight) - height[i]; }

Time: O(n²)  |  Space: O(1)

Approach 2: Dynamic Programming (Prefix/Suffix Arrays)

Precompute maxLeft[] and maxRight[] arrays in a single pass each, then compute water in a third pass.

Code

const maxLeft = [], maxRight = []; maxLeft[0] = height[0]; for (let i = 1; i < n; i++) maxLeft[i] = Math.max(maxLeft[i-1], height[i]); maxRight[n-1] = height[n-1]; for (let i = n-2; i >= 0; i--) maxRight[i] = Math.max(maxRight[i+1], height[i]); for (let i = 0; i < n; i++) sum += Math.min(maxLeft[i], maxRight[i]) - height[i];

Time: O(n)  |  Space: O(n)

Approach 3: Two Pointers (Optimal)

Use two pointers moving inward, tracking leftMax and rightMax on the fly. The smaller side determines water level.

Visual: Pointer Movement

left →
height[left] < height[right]
process left side
← right
  • If height[left] < height[right]: water is bounded by leftMax
  • If height[left] ≥ leftMax: update leftMax (no water here)
  • Else: add leftMax - height[left] to water
  • Mirror logic applies for the right pointer

Code

let left = 0, right = height.length - 1; let leftMax = 0, rightMax = 0, water = 0; while (left < right) { if (height[left] < height[right]) { if (height[left] >= leftMax) leftMax = height[left]; else water += leftMax - height[left]; left++; } else { if (height[right] >= rightMax) rightMax = height[right]; else water += rightMax - height[right]; right--; } } return water;

Time: O(n)  |  Space: O(1)
