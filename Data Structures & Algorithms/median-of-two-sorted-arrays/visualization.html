Median of Two Sorted Arrays

LeetCode 4

Array Binary Search Divide and Conquer

Problem Overview

Given two sorted arrays nums1 and nums2 of size m and n, return the median of the two sorted arrays in O(log(m+n)) time.

Input: nums1 = [1,3], nums2 = [2] Output: 2.0 Explanation: Merged = [1,2,3], median is 2. Input: nums1 = [1,2], nums2 = [3,4] Output: 2.5 Explanation: Merged = [1,2,3,4], median = (2+3)/2 = 2.5

Approach 1: Merge and Sort

O((m+n) log(m+n))

Combine both arrays into one, sort, and find the median directly.

Time: O((m+n) log(m+n)) Space: O(m+n)

Approach 2: Two Pointers (Linear Merge)

O(m+n)

Use two pointers to simulate the merge process (like merge sort's merge step) and stop at the middle element(s).

Time: O(m+n) Space: O(1)

Linear Merge: nums1=[1,2], nums2=[3,4]

Step 1 p1=0, p2=0: 1 < 3 → pick 1, merged=[1]
Step 2 p1=1, p2=0: 2 < 3 → pick 2, merged=[1,2]
Step 3 p1=2, p2=0: p1 done → pick 3, merged=[1,2,3]
Step 4 p2=1: pick 4, merged=[1,2,3,4]
1
2
3
4

Even length → Median = (2+3)/2 = 2.5

Approach 3: Binary Search Partition

Optimal — O(log min(m,n))

Binary search on the smaller array to find a partition point where all left elements are ≤ all right elements across both arrays.

Time: O(log min(m,n)) Space: O(1)

Binary Search Partition: nums1=[1,3], nums2=[2]

Total elements = 3, half = 2. Binary search on nums1 (smaller array).

Partition Concept

Find a cut such that left half elements ≤ right half elements across both arrays.

Left Half
All ≤ right
|
Right Half
All ≥ left

If sizes are equal and cross-condition holds, we've found the partition.

Approach Comparison

Approach Time Space Notes
Merge and Sort O((m+n) log(m+n)) O(m+n) Simplest to implement
Two Pointers O(m+n) O(1) Linear time, very intuitive
Binary Search O(log min(m,n)) O(1) Most efficient, careful implementation needed
