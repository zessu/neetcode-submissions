Longest Substring Without Repeating Characters

LeetCode 3

String Sliding Window Hash Table Two Pointers

Problem Overview

Given a string s, find the length of the longest substring without repeating characters.

Input: s = "abcabcbb" Output: 3 Explanation: The longest substring is "abc", with length 3.

Constraints: 0 <= s.length <= 5 × 104, consists of English letters, digits, symbols, and spaces.

Approach 1: Brute Force

O(n²)

For every starting index i and ending index j, check whether s[i..j] has any duplicate characters. Track the maximum valid length.

Time: O(n²) Space: O(min(n, σ))

Approach 2: Sliding Window with Set

Optimal — O(n)

Maintain a window [left, right] and a set of characters currently inside it. Expand the right end; if the new character is already in the set, shrink from the left until it isn't.

Time: O(n) Space: O(min(n, σ))

const charSet = new Set(); let leftPtr = 0, res = 0; for (let rightPtr = 0; rightPtr < s.length; rightPtr++) { while (charSet.has(s[rightPtr])) { charSet.delete(s[leftPtr]); leftPtr++; } charSet.add(s[rightPtr]); res = Math.max(res, rightPtr - leftPtr + 1); } return res;

Approach 3: Sliding Window with Last-Seen Map

Optimal — O(n)

Instead of removing characters one at a time, jump leftPtr directly to one past the previous occurrence of s[rightPtr].

Time: O(n) Space: O(min(n, σ))

No inner while loop needed — direct jump to valid position.

const lastSeen = new Map(); let leftPtr = 0, res = 0; for (let rightPtr = 0; rightPtr < s.length; rightPtr++) { const c = s[rightPtr]; if (lastSeen.has(c) && lastSeen.get(c) >= leftPtr) { leftPtr = lastSeen.get(c) + 1; } lastSeen.set(c, rightPtr); res = Math.max(res, rightPtr - leftPtr + 1); } return res;

Approach Comparison

Approach Time Space Pros Cons
Brute Force O(n²) O(min(n,σ)) Easiest to write Slow for n = 5×104
Sliding Window + Set O(n) O(min(n,σ)) Single pass, standard pattern Inner while loop can iterate many times
Sliding Window + Map O(n) O(min(n,σ)) No inner while — direct jump Slightly more bookkeeping
