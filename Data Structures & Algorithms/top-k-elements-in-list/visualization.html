Top K Frequent Elements

Array Hash Table Sort Heap Bucket Sort LeetCode 347

Problem Overview

Given an integer array and an integer k, return the k most frequent elements.

Input: nums = [1, 1, 1, 2, 2, 3], k = 2 Output: [1, 2]

Approach 1: Hash Map + Sorting

Time: O(n log n) Space: O(n)

Count frequencies using a hash map, convert to array, sort by frequency descending, and take the top k.

Approach 2: Heap (Min-Heap of size k)

Time: O(n log k) Space: O(n)

Count frequencies, then maintain a min-heap of size k. For each element, if the heap exceeds k, remove the minimum. The heap contains the top k at the end.

Approach 3: Bucket Sort (Optimal)

Time: O(n) Space: O(n)

Count frequencies, then create buckets where the index represents the frequency. Iterate from highest frequency bucket down to collect the top k elements.

Comparison

Approach Time Space Description
Sorting O(n log n) O(n) Simple to implement, good for small n
Heap O(n log k) O(n) Good when k is much smaller than n
Bucket Sort O(n) O(n) Best theoretical time complexity
