Summing Squares

Structy #79 — Fewest perfect squares that sum to n

Dynamic Programming Memoization BFS

Problem Overview

Given a target n, return the minimum count of perfect squares (1, 4, 9, 16, ...) whose sum is exactly n. Squares may be reused.

Input: n = 12 Output: 3 // 4 + 4 + 4 Input: n = 13 Output: 2 // 9 + 4 Input: n = 0 Output: 0 // empty sum

The equivalent LeetCode problem is 279. Perfect Squares.

Approach 1: Brute-Force Recursion

Intuition: Subtract one square at a time and explore every choice. Keep the branch that reaches 0 using the fewest squares.

Time: exponential Space: O(n)
Recursion for n = 12 — every square is tried at every level
12 → -1  (subtract 16)
12 → 3  (subtract 9) → 2 → 1 → 0 4 squares
12 → 8  (subtract 4) → 4 → 0 3 squares ✓
12 → 11  (subtract 1) → ... more than 3

The same remainder (for example 8 or 4) is reached by many different paths and recomputed each time.

Approach 2: Memoized DFS (Implemented)

Intuition: Cache the answer for each remainder. Once recurr(8) is known to be 2, every branch that reaches 8 reuses it in O(1).

Time: O(n · √n) Space: O(n)
Memoized recursion tree for n = 12 (green = cached result)
current state cached answer explored branch
const range = Math.floor(Math.sqrt(n)); const cache = new Map(); const recurr = (remain) => { if (remain < 0) return Infinity; if (remain === 0) return 0; if (cache.has(remain)) return cache.get(remain); let result = Infinity; for (let i = 1; i <= range; i++) { const res = recurr(remain - i * i); if (res !== Infinity) result = Math.min(result, res + 1); } cache.set(remain, result); return result; };

The cached path for 12 is 12 → 8 → 4 → 0: subtract 4 three times. That is 4 + 4 + 4, so the answer is 3.

Approach 3: Bottom-Up DP

Intuition: Fill dp[0..n] in increasing order. dp[t] depends only on smaller targets, which are already solved.

At t = 12: dp[11] + 1 = 4, dp[8] + 1 = 3, dp[3] + 1 = 4. The minimum is 3.

dp[0] = 0; for (let t = 1; t <= n; t++) { for (let i = 1; i * i <= t; i++) { dp[t] = Math.min(dp[t], dp[t - i * i] + 1); } }

The table has no recursion, so it cannot overflow the call stack. It computes every target from 0 to n, even targets that a particular DFS branch would never visit.

Approach 4: BFS over Remainders

Intuition: Each remainder is a node, and subtracting a square is an edge of weight 1. The minimum number of squares is the shortest path from n to 0.

Time: O(n · √n) Space: O(n)

The first time 0 is generated, the current level 3 is the minimum count. Duplicate remainders are skipped with a visited set.

Approach 5: Four-Square Theorem

Intuition: Lagrange proved every non-negative integer is the sum of at most four squares. The answer can only be 0, 1, 2, 3, or 4. Legendre's theorem identifies exactly when four are required.

Time: O(√n) Space: O(1)
0
n = 0
1
n is a perfect square
2
n = a² + b²
4
n = 4a(8b + 7)
3
everything else

For 12: removing factors of 4 leaves 3, which is not 8b + 7, and 12 is not a sum of two squares, so the answer is 3. For 13: 13 = 3² + 2², so the answer is 2.
