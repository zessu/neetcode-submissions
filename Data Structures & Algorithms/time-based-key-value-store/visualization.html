Time Based Key-Value Store

Hash Table String Binary Search Design LeetCode 981

Problem Overview

Design a time-based key-value data structure that stores multiple values for the same key at different timestamps and retrieves the key's value at a given timestamp (or the latest timestamp before it).

set("foo", "bar", 1) → stores "bar" at timestamp 1 get("foo", 1) → "bar" get("foo", 3) → "bar" (latest ≤ 3) set("foo", "bar2", 4) → stores "bar2" at timestamp 4 get("foo", 4) → "bar2" get("foo", 5) → "bar2" (latest ≤ 5)

Approach 1: Hash Map + Linear Scan

set: O(1) get: O(n) Space: O(n)

Store (timestamp, value) pairs in a list for each key. Use linear scan to find the latest valid timestamp ≤ the query timestamp.

After set("foo", "bar", 1) and set("foo", "bar2", 4)
"foo"
t=1 → "bar"
t=4 → "bar2"
get("foo", 3) — Linear scan backwards
"foo"
t=1 → "bar"
t=4 → "bar2" (skip, 4>3)
→ "bar" (t=1 is largest ≤ 3)

Approach 2: Hash Map + Binary Search (Optimal)

set: O(1) get: O(log n) Space: O(n)

Since timestamps are strictly increasing, the values are naturally sorted. Use binary search to find the largest timestamp ≤ the query timestamp.

Internal structure: timestamps are sorted
"foo"
t=1 → "bar"
t=4 → "bar2"
get("foo", 3) — Binary search on timestamps [1, 4]
1
4

mid=1 (val=4) > 3 → right=0. mid=0 (val=1) ≤ 3 → result=t=1

→ "bar"
get("foo", 5) — Binary search on timestamps [1, 4]
1
4

mid=0 (val=1) ≤ 5 → result=t=1. mid=1 (val=4) ≤ 5 → result=t=4

→ "bar2"
