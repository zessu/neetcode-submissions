Encode and Decode Strings

String Design LeetCode 271

Problem Overview

Design an algorithm to encode a list of strings into a single string and decode it back. The encoded string is sent over the network.

Input: ["neet", "code"] Encode: "4,4,#neet code" Decode: ["neet", "code"]

Approach 1: Special Delimiter

Time: O(n) Space: O(k)

Join strings with a delimiter character that doesn't appear in the strings. Problematic if all ASCII characters are allowed in input.

Encode with delimiter "#"
"neet"
"code"
↓
neet
#
code

Fails if input contains "#": ["ne#et", "code"] → ambiguous!

Approach 2: Length Prefix (Optimal)

Time: O(n) Space: O(1) extra

For each string, store its length followed by a delimiter, then the string itself. This robustly handles any character in the input strings.

Encode: ["neet", "code"]
"neet" (len=4)
"code" (len=4)
↓
4,
4,
#
neet code

Format: length1,length2,...,#content1 content2...

Decode: "4,4,#neet code"
Read "4,4" → sizes = [4, 4]
↓
Skip "#", read 4 chars → "neet"
↓
Skip space, read 4 chars → "code"
↓
"neet"
"code"
Handles any character including delimiters
"ne#et"
"co,de"
↓
5,
5,
#
ne#et co,de

Lengths tell us exactly how many chars to read — no ambiguity!

Comparison

Approach Reliability Efficiency Notes
Special Delimiter Low High Fails if delimiter exists in input
Length Prefix High High Handles any character robustly
