LeetCode 739 — Days to wait for a warmer temperature

Array Stack Monotonic Stack

Problem Overview

Given an array of temperatures, return an array where answer[i] is the number of days you must wait after day i for a warmer temperature. If none, answer is 0.

Input: [73, 74, 75, 71, 69, 72, 76, 73] Output: [1, 1, 4, 2, 1, 1, 0, 0]

Approach 1: Brute Force

Intuition: For each day, scan forward until a warmer day is found.

Time: O(n²) Space: O(1)
For each day, scan right for warmer temp
Day 0 (73) → check 74 > 73? → Yes! answer=1
Day 2 (75) → 71, 69, 72... → 76 > 75, answer=4

Too slow for n = 10&sup5; — O(n²) comparisons.

Approach 2: Monotonic Stack (Optimal)

Intuition: Maintain a stack of indices waiting for a warmer day. When a warmer day arrives, pop and resolve all waiting days.

Time: O(n) Space: O(n)

  1. Create result array initialized to 0, and an empty stack
  2. For each day i, while current temp > temp at stack top: pop and set result[popped] = i - popped
  3. Push current index i onto stack
  4. Remaining indices in stack already have result = 0
const result = new Array(n).fill(0); const stack = []; // stores indices for (let i = 0; i < n; i++) { while (stack.length > 0 && temps[i] > temps[stack.top()]) { const prev = stack.pop(); result[prev] = i - prev; } stack.push(i); }

Approach 3: DP (Optimized Forward Scan)

Intuition: Iterate right-to-left. Use previously computed answers to jump ahead, skipping days that are cooler.

Time: O(n) Space: O(1) extra
for (let i = n - 2; i >= 0; i--) { let j = i + 1; while (j < n && temps[j] <= temps[i]) { if (result[j] === 0) { j = n; break; } j += result[j]; } result[i] = j < n ? j - i : 0; }

Approach Comparison

Approach Time Space Pros Cons
Brute Force O(n²) O(1) Simple to implement Too slow for n = 10&sup5;
Monotonic Stack O(n) O(n) Clean, standard optimal solution Extra space for stack
DP (Optimized) O(n) O(1) In-place, optimal time and space More complex pointer logic
