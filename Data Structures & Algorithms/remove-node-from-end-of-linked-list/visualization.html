Remove Nth Node From End of List

LeetCode 19 — Remove the n-th node from the end of a linked list

Linked List Two Pointers

Problem Overview

Given a linked list, remove the n-th node from the end and return the head.

Input: head = [1,2,3,4,5], n = 2 Output: [1,2,3,5] (remove 4, the 2nd from end)

Approach 1: Two Pass (Length Calculation)

Intuition: Count total nodes, then traverse to the node before the target.

Time: O(sz) Space: O(1)
Pass 1: Count = 5, target position = 5 - 2 = 3
Pass 1: count nodes = 5
Target from start: 5 - 2 = 3rd node
Pass 2: traverse to 3rd, remove next

Approach 2: Reverse, Remove, Reverse (Implemented)

Intuition: Reverse the list, remove n-th from start, reverse back.

Time: O(sz) Space: O(1)
Original list: [1,2,3,4,5], n = 2
1→ 2→ 3→ 4→ 5

4 is the 2nd node from the end.

Step 1: Reverse the list
5→ 4→ 3→ 2→ 1
Step 2: Remove 2nd node from start (value 4)
5→ 4→ 3→ 2→ 1
After removal: [5,3,2,1]
Step 3: Reverse back
1→ 2→ 3→ 5
Normal node
Target to remove
Removed node
Result node
  1. Reverse the linked list
  2. Remove the n-th node from the start
  3. Reverse the list again
  4. Return the new head
removeNthFromEnd(head, n) { head = this.reverseList(head); head = this.removeElement(head, n); head = this.reverseList(head); return head; }

Approach Comparison

Approach Time Space Pros Cons
Two Pass O(sz) O(1) Simple, intuitive Requires two passes
Reverse, Remove, Reverse O(sz) O(1) Converts to simpler problem Three passes, modifies list
One Pass (Two Pointers) O(sz) O(1) Single pass, optimal Trickier to implement
