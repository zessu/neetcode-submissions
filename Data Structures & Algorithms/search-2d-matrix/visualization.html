Search a 2D Matrix

Array Binary Search Matrix LeetCode 74

Problem Overview

Given an m x n 2D matrix where each row is sorted in non-decreasing order and the first integer of every row is greater than the last integer of the previous row, determine if a target value exists in the matrix.

matrix = [[1, 2, 4, 8], [10,11,12,13], [14,20,30,40]] target = 10 Output: true

Approach 1: Brute Force

Time: O(m * n) Space: O(1)

Iterate through every element in the matrix and check if it equals the target.

Approach 2: Two-Pass Binary Search

Time: O(log m + log n) Space: O(1)

Approach 3: One-Pass Binary Search (Optimal)

Time: O(log(m * n)) Space: O(1)

Treat the 2D matrix as a virtual 1D sorted array. Convert 1D index to 2D coordinates: row = index / n, col = index % n.

Comparison

Approach Time Space Description
Brute Force O(m * n) O(1) Scan every cell
Two-Pass Binary O(log m + log n) O(1) Find row then find column
