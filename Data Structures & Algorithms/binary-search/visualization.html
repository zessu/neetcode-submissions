LeetCode 704 — Search for a target in a sorted array

Array Binary Search

Problem Overview

Given a sorted array nums and a target, return the index of target. If not found, return -1. Must run in O(log n).

Input: nums = [-1, 0, 3, 5, 9, 12], target = 9 Output: 4

Intuition: Scan every element one by one. Does not take advantage of the sorted property.

  1. Initialize left = 0, right = nums.length - 1
  2. While left ≤ right, calculate mid = left + (right - left) / 2
  3. If nums[mid] === target, return mid
  4. If nums[mid] < target, search right: left = mid + 1
  5. If nums[mid] > target, search left: right = mid - 1
let left = 0, right = nums.length - 1; while (left <= right) { const mid = Math.floor(left + (right - left) / 2); if (nums[mid] === target) return mid; else if (nums[mid] < target) left = mid + 1; else right = mid - 1; } return -1;

Approach 3: Recursive Binary Search

Intuition: Same logic as iterative, but uses recursion to divide the problem.

Time: O(log n) Space: O(log n) stack
function binarySearch(nums, target, left, right) { if (left > right) return -1; const mid = Math.floor(left + (right - left) / 2); if (nums[mid] === target) return mid; if (nums[mid] < target) return binarySearch(nums, target, mid + 1, right); return binarySearch(nums, target, left, mid - 1); }

Approach Comparison

Approach Time Space Pros Cons
Linear Search O(n) O(1) Simple, works on unsorted arrays Very slow for large n
Iterative Binary O(log n) O(1) Most efficient space usage Requires sorted array
Recursive Binary O(log n) O(log n) Easier to reason about Stack overhead
