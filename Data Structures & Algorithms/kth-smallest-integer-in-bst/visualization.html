Kth Smallest Element in a BST

LeetCode 230 — the k-th value of an inorder traversal

Tree DFS BST Inorder

Problem Overview

Return the k-th smallest value (1-indexed) in a binary search tree. Because a BST's inorder traversal is sorted, this is the k-th value emitted by left → node → right.

Input: root = [5, 3, 6, 2, 4, null, null, 1], k = 3 5 / \ 3 6 / \ 2 4 / 1 Inorder: 1, 2, 3, 4, 5, 6 ^ 3rd = 3 Output: 3

Approach 1: Brute Force — Collect and Sort

Intuition: Ignore the BST property, gather every value, sort, and index k - 1.

Time: O(n log n) Space: O(n)
Collect, sort, then index
collected 536 241
sorted 123 456 k = 3 → zero-based index 2 → value 3

Correct, but the sort is wasted work: an inorder walk already produces the sorted order.

Approach 2: Recursive Inorder, Collect All (Implemented)

Intuition: Traverse left → node → right and append every value. The array is sorted for free, so return results[k - 1].

Time: O(n) Space: O(n) + O(h)
Inorder visit order on the example tree
Emitted before k
k-th value (answer)
Emitted after k (wasted work)

This implementation still visits 4, 5, and 6 even though the answer was known at 3.

results = [1, 2, 3, 4, 5, 6] → results[3 - 1] = 3

Approach 3: Iterative Inorder with Early Exit

Intuition: Descend left while pushing nodes. Pop the next inorder node, count it, and stop as soon as the count reaches k. Then move into its right subtree.

Time: O(h + k) Space: O(h)
Stack trace for k = 3
descend 5321 Push 5, 3, 2, 1 while moving left.
pop 1 532 count = 1 ≠ 3. Node 1 has no right child.
pop 2 53 count = 2 ≠ 3. Node 2 has no right child.
pop 3 5 count = 3 === k ⇒ return 3 immediately; 4, 5, 6 are never touched.
return 3
while (curr || stack.length) { while (curr) { stack.push(curr); curr = curr.left; } const node = stack.pop(); if (++count === k) return node.val; curr = node.right; }

Approach 4: Morris Inorder (O(1) Space)

Intuition: Before descending into a left subtree, thread its rightmost node back to the current node. After that subtree is emitted, the thread brings the walk back so the node itself can be emitted. Remove each thread when it is used.

Time: O(n) Space: O(1)
Threads used during the walk (not all present at once)

Threads point from a subtree's rightmost node to its successor. Morris emits 1, 2, 3, so the answer is known at k = 3. Finishing the walk removes every thread; returning immediately would leave 4 → 5 in place.

  1. curr = 5: find pred = 4, set 4.right = 5, descend left to 3.
  2. curr = 3: find pred = 2, set 2.right = 3, descend left to 2.
  3. curr = 2: find pred = 1, set 1.right = 2, descend left to 1.
  4. curr = 1: no left child → emit 1 (1st), follow the thread to 2.
  5. curr = 2: thread detected → remove it, emit 2 (2nd), then follow its remaining right thread to 3.
  6. curr = 3: thread detected → remove it, emit 3 (3rd). The answer is known; finishing the walk would emit 4, 5, 6 and remove the remaining 4 → 5 thread.

Approach Comparison

Approach Time Space Pros Cons
Collect and Sort O(n log n) O(n) Works for any tree Ignores the BST property
Recursive Inorder, collect all (implemented) O(n) O(n) + O(h) Shortest correct BST solution Visits all n nodes even for k = 1
Iterative Inorder, early exit O(h + k) O(h) Stops at the answer; no recursion More code and explicit stack
Morris Inorder O(n) O(1) Constant auxiliary memory Temporarily rewires pointers; subtle

Key Insight & Common Pitfalls

Key insight: a BST inorder traversal emits values in ascending order, so the k-th smallest is the k-th emitted value. No sorting or comparisons are needed.
Pitfall: k is 1-indexed. Arrays use results[k - 1]; the counter version must increment before comparing count === k.
Pitfall: in the iterative version, push the node before moving left, and pop only after the left subtree is exhausted.
Pitfall: Morris must remove each thread (pred.right = null), or the walk loops forever.
Pitfall: for frequent insert/delete plus k-th queries, a plain traversal is O(n). Augment nodes with left-subtree sizes (an order-statistic tree) to get O(h) queries and updates.
