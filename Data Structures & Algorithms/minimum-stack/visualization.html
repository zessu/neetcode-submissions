Stack Design

Problem Overview

Design a stack that supports push, pop, top, and getMin in constant O(1) time.

Operations: ["MinStack","push","push","push","getMin","pop","top","getMin"] [[],[-2],[0],[-3],[],[],[],[]] Output: [null, null, null, null, -3, null, 0, -2]

Approach 1: Brute Force getMin

getMin: O(n)

Use a single stack. For every getMin call, scan the entire stack to find the minimum.

push/pop: O(1) getMin: O(n) Space: O(n)

Approach 2: Auxiliary Min Stack

Optimal — All O(1)

Maintain a second stack (minStack) that records the minimum value at each level of the main stack. Both stacks grow and shrink in sync.

All ops: O(1) Space: O(n)

class MinStack { constructor() { this.stack = []; this.minStack = []; } push(val) { this.stack.push(val); if (this.minStack.length === 0 || val <= this.minStack[this.minStack.length - 1]) { this.minStack.push(val); } else { this.minStack.push(this.minStack[this.minStack.length - 1]); } } pop() { this.stack.pop(); this.minStack.pop(); } top() { return this.stack[this.stack.length - 1]; } getMin() { return this.minStack[this.minStack.length - 1]; } }
