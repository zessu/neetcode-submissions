Koko Eating Bananas

LeetCode 875 — Find minimum eating speed to finish in h hours

Binary Search Math

Problem Overview

Koko must eat all banana piles within h hours. She eats k bananas/hour from one pile. If a pile has fewer than k, she finishes it and waits. Find the minimum k.

Input: piles = [3, 6, 7, 11], h = 8 Output: 4 (speed of 4 bananas/hour finishes in exactly 8 hours)

Approach 1: Brute Force

Intuition: Try every speed from 1 upward until finding the first that works.

Time: O(n · max(piles)) Space: O(1)
Try each speed k = 1, 2, 3, ... until hours ≤ h
k=1 → 3+6+7+11 = 27 hours > 8
k=2 → 2+3+4+6 = 15 hours > 8
k=3 → 1+2+3+4 = 10 hours > 8
k=4 → 1+2+2+3 = 8 hours ≤ 8

Works but extremely slow when max(piles) = 10^9.

Approach 2: Binary Search (Optimal)

Intuition: The speed range [1, max(piles)] is monotonic — if speed k works, any higher speed also works. Binary search finds the minimum valid k.

Time: O(n · log(max(piles))) Space: O(1)
Banana piles: [3, 6, 7, 11], h = 8

  1. Set left = 1, right = max(piles)
  2. Calculate mid = floor((left + right) / 2)
  3. Sum ceil(pile / mid) for all piles
  4. If total hours ≤ h: valid, try lower (right = mid - 1)
  5. If total hours > h: too slow, try higher (left = mid + 1)
  6. Return left when loop exits
let left = 1, right = Math.max(...piles); while (left <= right) { const mid = Math.floor((left + right) / 2); let hours = 0; for (const pile of piles) { hours += Math.ceil(pile / mid); } if (hours <= h) right = mid - 1; else left = mid + 1; } return left;

Approach Comparison

Approach Time Space Pros Cons
Brute Force O(n · m) O(1) Simple logic Very slow for m = 10^9
Binary Search O(n · log m) O(1) Fast and efficient Requires monotonic search space
