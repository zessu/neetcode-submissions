Binary Tree Inorder Traversal

LeetCode 94 — Return the left-root-right sequence of node values

Easy Stack Tree Depth-First Search Binary Tree

Problem Overview

Return the inorder traversal of a binary tree: fully explore the left subtree, then visit the node, then fully explore the right subtree.

For the tree below, the left child of 2 is visited before 2 itself, even though 2 is higher in the tree. The result is [1, 3, 2].

Input: root = [1,null,2,3] Output: [1,3,2] Follow-up: can you do it iteratively?

Approach 1: Recursive DFS (Implemented)

Intuition: Inorder is defined recursively. Recurse left, record the current value, recurse right. The call stack remembers the path back to each unfinished node.

Time: O(n) Space: O(h)
Visit order for [1,null,2,3] — badges show when each node is recorded
traverse(1): go left (null), visit 1, go right
traverse(2): go left to 3 before visiting 2
traverse(3): left null, visit 3, right null → visit 2
output = [1, 3, 2]

Visit-order badge
  1. If the node is null, return.
  2. Recurse into the left child.
  3. Push the current value onto the result.
  4. Recurse into the right child.
  5. Return the result after the initial call finishes.
const res = []; const traverse = (node) => { if (!node) return; traverse(node.left); res.push(node.val); traverse(node.right); }; traverse(root); return res;

Approach 2: Iterative with an Explicit Stack

Intuition: Simulate the recursion. Push every node on the path to the leftmost leaf. When there is no left child, pop and visit a node, then continue into its right subtree.

Each node enters and leaves the stack exactly once. The inner "walk left" loop does not make the algorithm quadratic.

  1. Set curr = root, stack = [].
  2. While curr is not null, push it and move left.
  3. Pop the top node, append its value, and move to its right child.
  4. Repeat until both curr and the stack are empty.
const stack = [], res = []; let curr = root; while (curr || stack.length) { while (curr) { stack.push(curr); curr = curr.left; } curr = stack.pop(); res.push(curr.val); curr = curr.right; } return res;

Approach 3: Morris Traversal (O(1) Space)

Intuition: Use the tree's empty right pointers as temporary "return threads". For a node with a left subtree, link the rightmost node of that left subtree back to the node. After the left subtree is processed, the thread leads back so the node can be visited and the thread removed.

Time: O(n) Space: O(1)
Temporary thread from 3 back to 2
curr = 1: no left → visit 1, curr = 2
curr = 2: left = 3, pred = 3, pred.right = null → set thread, curr = 3
curr = 3: no left → visit 3, follow the thread to 2
curr = 2: pred.right already points to 2 → remove thread, visit 2, curr = null
output = [1, 3, 2]
  1. If there is no left child, visit the node and move right.
  2. Otherwise, find the rightmost node in the left subtree (the inorder predecessor).
  3. If its right is null, link it to the current node and move left.
  4. If its right already points to the current node, remove the link, visit the node, and move right.
  5. Continue until curr becomes null.
let curr = root; while (curr) { if (!curr.left) { res.push(curr.val); curr = curr.right; } else { let pred = curr.left; while (pred.right && pred.right !== curr) pred = pred.right; if (!pred.right) { pred.right = curr; curr = curr.left; } else { pred.right = null; res.push(curr.val); curr = curr.right; } } } return res;

Approach Comparison

Approach Time Space Notes
Recursive DFS (implemented) O(n) O(h) Clearest expression of left-root-right; uses the call stack.
Iterative stack O(n) O(h) Same complexity, no recursion; expected answer to the follow-up.
Morris traversal O(n) O(1) Constant auxiliary space; temporarily rewires and restores the tree.

Key Insights & Common Pitfalls

Key insight: A node is recorded between its two recursive calls. Change the position of that one statement and you get preorder (record first) or postorder (record last).

  • Recording too early. Pushing before the left recursion gives preorder, not inorder.
  • Missing the null base case. Leaves have null children; without the base case the recursion never stops.
  • Iterative order. Push while walking left, then pop and visit; pushing right children early breaks the order.
  • Shared result array. A class-level res accumulates across calls if the same instance is reused; reset it or use a local array.
  • Morris cleanup. Always remove temporary threads, or the tree stays modified and traversal may loop.
  • Empty input. Return [], not [null].
