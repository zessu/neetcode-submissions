Contains Duplicate

LeetCode 217 — Check if any value appears at least twice

Array Hash Table Sorting

Problem Overview

Given an integer array nums, return true if any element appears at least twice, false if all elements are distinct.

Input: nums = [1, 2, 3, 1] Output: true (1 appears twice)

Approach 1: Brute Force

Intuition: Compare every pair of elements to check for duplicates.

Time: O(n²) Space: O(1)
Check all pairs in [1, 2, 3, 1]
(1,2) no (1,3) no (1,1) YES!

Checks n(n-1)/2 pairs — extremely slow for large arrays.

Approach 2: Sorting

Intuition: Sort the array so duplicates become adjacent. Then check consecutive elements.

Time: O(n log n) Space: O(1)
Sort then check adjacent elements

  1. Sort the input array
  2. Iterate from i = 1 to n-1
  3. If nums[i] == nums[i-1], return true
  4. If loop completes, return false

const seen = new Set(); for (const num of nums) { if (seen.has(num)) return true; seen.add(num); } return false;
