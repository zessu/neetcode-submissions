Sort Colors

LeetCode 75 — Group 0s, 1s, and 2s in place

Array Two Pointers Sorting Counting Sort

Problem Overview

Given an array containing only 0, 1, and 2, sort it in place so all 0s come first, then all 1s, then all 2s. Do not use the library sort. Follow-up: do it in one pass with constant space.

Input: nums = [2,0,2,1,1,0] Output: [0,0,1,1,2,2] Input: nums = [2,0,1] Output: [0,1,2]

Approach 1: Counting Sort (Implemented)

Intuition: Count how many of each color exist, then overwrite the array with that many 0s, then 1s, then 2s. Writing values in increasing order produces the grouping for free.

Key Insights & Pitfalls

Key insight: with only three distinct values, sorting is really partitioning. Counting sort writes the groups directly; the Dutch National Flag algorithm builds the same groups in one pass using the invariant [0,low) = 0s, [low,mid) = 1s, (high,n) = 2s.
Pitfall 1: After swapping a 2 from the right, do not advance mid — the value that just arrived has not been inspected.
Pitfall 2: When nums[mid] === 0, advance both low and mid. The value swapped into mid comes from the 1 region, so it is already known.
Pitfall 3: The DNF loop must run while mid <= high; mid < high skips the last unknown element.
Pitfall 4: Return nothing. The method mutates nums; returning a new sorted array does not help the caller.
Pitfall 5: Do not use nums.sort(); it is forbidden and, without a comparator, sorts lexicographically.
