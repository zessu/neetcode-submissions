Approach 1: Recursive

O(n+m) time, O(n+m) space

Compare the heads of both lists. The smaller head becomes the current node, and recursively merge the rest.

Time: O(n+m) Space: O(n+m) recursion stack

Recursion Tree

Call 1: merge(1→2→4, 1→3→4) → 1≤1, pick list1(1)
Call 2: merge(2→4, 1→3→4) → 2>1, pick list2(1)
Call 3: merge(2→4, 3→4) → 2≤3, pick list1(2)
Call 4: merge(4, 3→4) → 4>3, pick list2(3)
Call 5: merge(4, 4) → 4≤4, pick list1(4)
Call 6: merge(null, 4) → base case, return 4

Stack unwinds: 1 → 1 → 2 → 3 → 4 → 4

mergeTwoLists(list1, list2) { if (!list1) return list2; if (!list2) return list1; if (list1.val <= list2.val) { list1.next = this.mergeTwoLists(list1.next, list2); return list1; } else { list2.next = this.mergeTwoLists(list1, list2.next); return list2; } }

Approach 2: Iterative with Dummy Node

Optimal — O(1) space

Use a dummy node and a tail pointer. Always attach the smaller current node and advance that list's pointer.

Time: O(n+m) Space: O(1)

Iterative Merge Step-by-Step

Init dummy → null, tail = dummy
Step 1 1 ≤ 1 → attach list1(1), tail→1, advance list1
Step 2 2 > 1 → attach list2(1), tail→1, advance list2
Step 3 2 ≤ 3 → attach list1(2), tail→2, advance list1
Step 4 4 > 3 → attach list2(3), tail→3, advance list2
Step 5 4 ≤ 4 → attach list1(4), tail→4, advance list1
Step 6 list1=null → attach remaining list2(4)

const dummy = new ListNode(); let tail = dummy; while (list1 && list2) { if (list1.val <= list2.val) { tail.next = list1; list1 = list1.next; } else { tail.next = list2; list2 = list2.next; } tail = tail.next; } tail.next = list1 || list2; return dummy.next;

Approach Comparison

Approach Time Space Pros Cons
Recursive O(n+m) O(n+m) Clean, elegant code Stack overflow for large lists
Iterative O(n+m) O(1) No extra space, safe for large inputs Slightly more verbose
