Largest Component

Find the size of the largest connected component in an undirected graph

Graph DFS BFS Union-Find

Problem Overview

Given an undirected graph as an adjacency list, return the number of nodes in its largest connected component. A component is a maximal group of nodes where each node can reach every other node in the group.

Input: graph = { 0: [8,1,5], 1: [0], 5: [0,8], 8: [0,5], 2: [3,4], 3: [2,4], 4: [3,2], } Output: 4 ( {0,1,5,8} has 4 nodes, {2,3,4} has 3 )
Note: the submission's function is named largestComponent. An earlier scratch version called it longestPath, but a "longest path" is a different (NP-hard) problem — this task is a simple graph traversal.

Approach 1: Per-Node DFS (Implemented)

Intuition: The component containing a node is exactly the set of nodes reachable from it. So run a DFS from every node, count the nodes reached, and keep the maximum.

The two components of the sample graph
{0,1,5,8} → size 4
{2,3,4} → size 3

Every node re-traverses its whole component (redundant work)

A component of size k is visited k times — correct, but wasteful.

const largestComponent = (graph) => { let largest = 0; for (const [key, _] of Object.entries(graph)) { largest = Math.max(largest, navigate(graph, Number(key))); } return largest; }; const navigate = (graph, key) => { const visited = new Set(); let length = 0; const stack = [key]; while (stack.length) { const current = stack.pop(); if (visited.has(current)) continue; visited.add(current); length++; for (const neighbor of graph[current]) stack.push(neighbor); } return length; };

Approach 2: Single-Pass DFS/BFS (Optimal)

Intuition: Use one shared visited set. Each time we start a traversal from a node that has not been seen, we have discovered a brand-new component. Count its nodes and keep the maximum.

Time: O(V + E) Space: O(V)
One walk across the whole graph
node 0 unvisited → DFS finds {0,1,5,8}, size 4 → largest = 4
nodes 1, 5, 8 already visited → skip
node 2 unvisited → DFS finds {2,3,4}, size 3 → largest stays 4
nodes 3, 4 already visited → skip → return 4
  1. Create one global visited set and largest = 0.
  2. For each node, if it is already visited, skip it.
  3. Otherwise traverse from it (DFS or BFS), marking and counting each node reached.
  4. Update largest = max(largest, count).
  5. Return largest after the loop.
const largestComponent = (graph) => { const visited = new Set(); let largest = 0; for (const key of Object.keys(graph)) { const size = explore(graph, Number(key), visited); if (size > 0) largest = Math.max(largest, size); } return largest; }; const explore = (graph, node, visited) => { if (visited.has(node)) return 0; // already part of another component visited.add(node); let size = 1; for (const neighbor of graph[node]) size += explore(graph, neighbor, visited); return size; };

Approach 3: Union-Find (Disjoint Set Union)

Intuition: Merge the two endpoints of every edge into the same set, then report the largest set size. Useful when edges arrive incrementally.

Time: O((V + E) · α(V)) Space: O(V)
// parent[x] and size[x] for every node; union by size for (const [a, neighbors] of Object.entries(graph)) { for (const b of neighbors) union(Number(a), b); } return Math.max(...Object.keys(graph).map(x => size[find(Number(x))]));
