Group Anagrams

LeetCode 49 — Group strings that are anagrams of each other

Array Hash Table String Sorting

Problem Overview

Given an array of strings strs, group the anagrams together. An anagram is a word formed by rearranging the letters of another word using all original letters exactly once.

Input: ["eat", "tea", "tan", "ate", "nat", "bat"] Output: [["eat","tea","ate"], ["tan","nat"], ["bat"]]

Approach 1: Sorting

Intuition: Anagrams produce identical strings when sorted. Use the sorted string as a hash map key.

Time: O(m · n log n) Space: O(m · n)
Step-by-step: Sorting each string to form keys
"eat" → "aet"
"tea" → "aet"
"tan" → "ant"
"ate" → "aet"
"nat" → "ant"
"bat" → "abt"
HashMap grouping by sorted key
"aet"
"eat" "tea" "ate"
"ant"
"tan" "nat"
"abt"
"bat"
  1. Iterate through each string in the input list
  2. Sort the characters to form a canonical key
  3. Append the original string to the list for that key in the hash map
  4. Return all values from the hash map

Approach 2: Character Count Signature

Intuition: Two strings are anagrams if and only if they have identical character frequencies. Use the count array as the key instead of sorting.

Time: O(m · n) Space: O(m · n)
Character count signature for "eat"
"eat" → count = [1,0,0,0,1,0,...,0,1,0]
"tea" → count = [1,0,0,0,1,0,...,0,1,0]

Both produce the same 26-element count array → same key → grouped together

Key generation: count.join('#')
"eat" → "1#0#0#0#1#0#...#0#1#0"
"tan" → "1#0#0#0#0#0#...#1#0#0"
  1. Create a count array of size 26 for each string
  2. Increment count[char - 'a'] for each character
  3. Convert count array to a unique key string using join('#')
  4. Group strings by this key in a hash map

Approach Comparison

Approach Time Space Pros Cons
Sorting O(m · n log n) O(m · n) Simple to implement, works for any charset Slower for long strings
Char Count O(m · n) O(m · n) Linear time, theoretically faster Slightly more complex key generation
