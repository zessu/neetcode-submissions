Invert Binary Tree

LeetCode 226 — Swap left and right children of every node

Tree DFS BFS

Problem Overview

Invert a binary tree by swapping the left and right children of every node.

Input: root = [4,2,7,1,3,6,9] Output: [4,7,2,9,6,3,1]

Approach 1: BFS (Level Order)

Intuition: Traverse level by level, swapping children at each node.

Time: O(n) Space: O(w)
Queue-based level order traversal
Queue: [4] → swap children → enqueue 7, 2
Queue: [7, 2] → process 7: swap 6, 9
Queue: [2, 6, 9] → process 2: swap 1, 3
Queue: [6, 9, 1, 3] → all leaves, done

Approach 2: Recursive DFS (Optimal)

Intuition: Swap at each node, then recursively invert both subtrees.

Time: O(n) Space: O(h)
Before inversion
After inversion
Recursive steps
Node 4: swap left(2) and right(7)
Node 7: swap left(6) and right(9)
Node 2: swap left(1) and right(3)
Original node
After swap
  1. If node is null, return null
  2. Swap left and right children
  3. Recursively invert left subtree
  4. Recursively invert right subtree
  5. Return root
invertTree(root) { if (root === null) return null; [root.left, root.right] = [root.right, root.left]; this.invertTree(root.left); this.invertTree(root.right); return root; }

Approach Comparison

Approach Time Space Pros Cons
BFS O(n) O(w) Iterative, no stack overflow Uses queue, more code
Recursive DFS O(n) O(h) Elegant, minimal code Stack overflow for skewed trees
