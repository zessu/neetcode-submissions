Reorder Linked List

Linked List Two Pointers Stack LeetCode 143

Problem Overview

Given the head of a singly linked-list, reorder it to:

L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → ...

You may not modify the values in the list's nodes. Only nodes themselves may be changed.

Input: [1, 2, 3, 4, 5] Output: [1, 5, 2, 4, 3]

Approach 1: Find Middle + Reverse + Merge (Optimal)

Time: O(n) Space: O(1)

Split the list in half, reverse the second half, then merge the two halves alternately.
