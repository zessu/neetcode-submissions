LRU Cache

LeetCode 146 — Least Recently Used cache with O(1) operations

Hash Table Linked List Design

Problem Overview

Design a cache that evicts the least recently used item when capacity is reached. Both get and put must run in O(1) time.

Capacity: 2 Operations: put(1,1), put(2,2), get(1), put(3,3), get(2), put(4,4), get(1), get(3), get(4) Output: [null, null, null, 1, null, -1, null, -1, 3, 4]

Approach 1: Hash Map + Array

Intuition: Use a map for lookups and an array to track access order.

Time: O(1) get, O(n) put Space: O(capacity)
Array shift on every access makes put O(n)
get(1): find 1 in array, move to end (O(n))
put(3,3): evict first, shift all (O(n))

Array operations are O(n), not meeting the O(1) requirement.

Approach 2: Hash Map Using Map Insertion Order (Optimal)

Intuition: JavaScript's Map preserves insertion order. Delete + re-insert marks as recently used.

Time: O(1) Space: O(capacity)
LRU ← --- Cache (capacity 2) --- → MRU

put(1, 1):

1= 1

put(2, 2):

1= 1 → 2= 2

get(1): found, move to end

2= 2 → 1= 1

put(3, 3): evict LRU (key 2)

2= 2 (evicted) → 1= 1 → 3= 3

get(2): not found

Return -1

put(4, 4): evict LRU (key 1)

1= 1 (evicted) → 3= 3 → 4= 4
Normal entry
Most recently used
LRU / Evicting
Being evicted
  1. get(key): if exists, delete and re-insert, return value; else return -1
  2. put(key, value): if key exists, delete and re-insert with new value
  3. If cache is full, evict the first key (LRU) before inserting
  4. Otherwise, simply insert the new key-value pair
get(key) { if (!this.store.has(key)) return -1; const value = this.store.get(key); this.store.delete(key); this.store.set(key, value); return value; } put(key, value) { if (this.store.has(key)) { this.store.delete(key); this.store.set(key, value); return; } if (this.store.size === this.capacity) { const lruKey = this.store.keys().next().value; this.store.delete(lruKey); } this.store.set(key, value); }
