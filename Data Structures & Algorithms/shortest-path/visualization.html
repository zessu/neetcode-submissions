Shortest Path

Find the fewest edges between two nodes in an undirected graph

Graph BFS Shortest Path

Problem Overview

Given an undirected graph as a list of edges plus a start and finish node, return the number of edges in the shortest path between them, or -1 if no path exists. Because every edge has equal weight, BFS finds the shortest route.

Input: edges = [['w','x'],['x','y'],['z','y'],['z','v'],['w','v']] start = "w", finish = "z" Output: 2 ( w → v → z )
Key idea: BFS visits nodes in order of distance, so the first time it dequeues finish, the stored distance is the shortest possible.

Approach 1: BFS by Levels (Implemented)

Intuition: Explore the graph in rings of increasing distance. Distance 0 is the start, distance 1 is its neighbors, distance 2 is their neighbors, and so on.

Time: O(V + E) Space: O(V)

pop [y, 2] → push [x, 3], [z, 3]
pop [z, 2] → z === finish, return 2
  1. Build an adjacency list, adding every edge in both directions.
  2. Enqueue [start, 0].
  3. Dequeue [node, dist]; skip if already visited.
  4. Mark it visited; if it is finish, return dist.
  5. Enqueue every neighbor as [neighbor, dist + 1].
  6. If the queue empties, return -1.
const shortestPath = (edges, start, finish) => { const adjList = buildAdjacencyGraph(edges); const queue = [[start, 0]]; const visited = new Set(); while (queue.length) { let [item, idx] = queue.shift(); if (visited.has(item)) continue; visited.add(item); if (item === finish) return Number(idx); for (const neighbor of adjList[item]) { queue.push([neighbor, Number(idx) + 1]); } } return -1; };

Approach 2: Dijkstra (for weighted graphs)

Intuition: When edges have different weights, a plain FIFO queue no longer visits nodes in distance order. Dijkstra uses a min-heap to always expand the closest known node.

Time: O((V + E) · log V) Space: O(V + E)
dist[start] = 0; heap = [[0, start]]; while (heap.length) { const [d, node] = popMin(heap); if (node === finish) return d; for (const [neighbor, w] of adj[node]) { if (d + w < dist[neighbor]) { dist[neighbor] = d + w; push(heap, [d + w, neighbor]); } } }

With unit weights this reduces to BFS with extra log V overhead — unnecessary here.

Approach 3: DFS / Backtracking (not optimal)

Intuition: Enumerate every path from start to finish and keep the shortest. This is correct but exponential, and it explores paths that BFS prunes immediately.

Time: O(V!) worst case Space: O(V)
const dfs = (node, dist) => { if (node === finish) { best = Math.min(best, dist); return; } for (const n of adj[node]) { if (!visited.has(n)) { visited.add(n); dfs(n, dist + 1); visited.delete(n); // backtrack } } };
